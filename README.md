# MailThreat Analyzer Informational Site

This folder contains a separate static informational website for MailThreat Analyzer.

## Publish on GitHub Pages

1. Push the repository to GitHub.
2. Open `Settings` for the repository.
3. Go to `Pages`.
4. Under `Build and deployment`, choose:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/docs`
5. Save the settings and wait for GitHub Pages to publish the site.

## Files

- `index.html`: main informational page
- `styles.css`: site styling
- `app.js`: lightweight client-side motion
- `assets/logo.png`: MailThreat Analyzer logo for the site

## Content Alignment

The copy in this site is intentionally aligned to the current implementation of MailThreat Analyzer, including:

- hybrid phishing detection
- Gmail-connected scanning
- simulator fallback
- explainable AI outputs
- Cortex-guided review
- analytics and threat visibility
- latency benchmarking support
