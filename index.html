Current Capabilities

What MailThreat Analyzer currently supports

The informational site reflects the live implementation rather than speculative features.

Authentication and access

Email/password access, Google sign-in, Gmail connection, and discounted-mode access for users who want manual email analysis before connecting Gmail.

Phishing detection pipeline

Feature extraction across message content, embedded links, sender patterns, reply-to behavior, behavioral pressure cues, grammar signals, and selected metadata indicators.

Explainable AI outputs

Threat scores, phishing labels, suspicious URL summaries, grouped risk breakdowns, identified risk factors, and response recommendations that help users understand why an email was flagged.

Inbox monitoring

Manual scanning, automated background monitoring for Gmail-connected users, and simulator-based testing when live inbox access is not available.

Cortex review workflows

Guided review before action, next-step routing for delete/quarantine/block decisions, persistent flagged-email history, and blocked-email record retention.

Analytics and visibility

Threat map views, reporting pages, dashboard activity summaries, threat trends, and latency benchmarking logs for research and operational review.

Workflow

How the platform works

MailThreat is designed as a practical, end-to-end phishing analysis environment rather than a standalone classifier.

01

Ingest

Connect Gmail through OAuth, analyze uploaded or pasted email content, or use the simulator for controlled testing.

02

Analyze

Extract features from subject lines, body text, URLs, sender identity, reply-to behavior, and other phishing-related cues.

03

Explain

Return a threat score, classification, risk breakdown, suspicious link details, and user-facing recommendations.

04

Respond

Let the user review findings and choose guided next steps such as delete, quarantine, or sender blocking where applicable.

Deployment Modes

Built for live use, fallback testing, and research benchmarking

The platform supports multiple operational contexts so it can be demonstrated, evaluated, and used under different constraints.

Gmail-connected mode

Uses Gmail OAuth and API access to retrieve and analyze inbox messages, support background monitoring, and preserve flagged-email history.

Discounted/manual mode

Lets users paste or upload email content for analysis before connecting Gmail, while clearly showing which features require Gmail access.

Simulator mode

Provides a controlled test inbox for repeatable demonstrations, development validation, and evaluation when live Gmail access is unavailable.

FAQ

Common questions

Does MailThreat replace Gmail spam filtering?

No. MailThreat is positioned as an additional analysis and response layer that emphasizes phishing scoring, explainability, user review, and research-driven visibility beyond ordinary filtering.

Does it require Gmail to work?

No. Gmail connection unlocks live inbox monitoring, but users can also analyze pasted or uploaded email content and use the simulator-based environment.

What kind of intelligence does the threat map show?

The current product includes threat visualization and analytics views based on platform incident data and records surfaced through the MailThreat workflow.

Why is explainable AI important here?

Phishing decisions are easier to trust and review when the system shows why an email was flagged instead of only returning a raw classification.
